專題題目一實證研究

產業 AI 自動化衝擊、實質薪資結構與少子化：
台灣縣市與總體層面的滯後傳導機制

本研究旨在解構台灣總體經濟榮景下出口與 AI 科技強勁成長，卻未能轉化為人口紅利的解耦現象 (Decoupling Puzzle)。結合 **技能偏向型技術進步 (SBTC)** 與 **擴充版貝克育兒質量模型**，透過 AREMOS 資料庫探討 AI 技術替代對實質薪資、育兒機會成本與總生育率之 1~4 年滯後影響。

SBTC 技能偏向衝擊

AI 與自動化提升高技能勞工邊際生產力，拉大極化薪資差距，使年輕高技能族群育兒時間成本高企，中低技能族群面臨替代風險與所得不確定性。

滯後 1~2 年傳導機制

結婚與懷孕決策具備高度時間滯後性 (Time Lag)。產業 AI 自動化對實質薪資與物價的波動，需經過 4~8 季的時間累積才會顯著反應於生育率驟降。

名目榮景 vs 實質約束

電子零組件出口與 M1B/M2 貨幣數量擴張推升整體 GDP 與房價，但一般家庭受 CPI 居住成本擠壓，實質購買力受限，造成育兒預算約束緊縮。

Theoretical Foundation

經濟學理傳導機制與研究假說

AI 自動化衝擊之總體與個體傳導鏈 (Transmission Mechanism)

階段 1
AI / 電子出口衝擊

資本快速替代勞動，高科技產業擴張

階段 2
薪資極化 (SBTC)

高技能薪資飆升，中低技能所得相對停滯

階段 3
育兒機會成本爆升

高薪族群時間成本 $w \cdot t_c$ 上升，替代效應 > 所得效應

階段 4
實質居住擠壓

CPI 與資產價格上漲，實質預算約束緊縮

最終結果
生育率遞延驟降

滯後 1~2 年，家庭選擇少生並提高單一子女教育 $q$

擴充版貝克育兒質量模型 (Extended Becker Model)

家庭代表性個體追求效用最大化，效用函數設定為子女數量 $n$、子女品質 $q$ 與一般消費 $z$ 之對數可分函數：

U(n, q, z) = α ln(n) + β ln(q) + γ ln(z)

受限於家庭預算與育兒時間約束，養育子女的單位價格 $p_n$ 包含實質時間機會成本與居住/托育成本：

p_n = w · t_c + P_{care} + P_{housing}

* 當 AI 自動化使實質工資 $w$ 大幅提升時，時間成本 $w \cdot t_c$ 之替代效應將主導育兒決策，導致子女數量 $n$ 降低，轉而拉高對品質 $q$ 的投入。

研究假說 H1 時間滯後假說

AI 自動化擴大技能薪資差距並提高育兒機會成本，對生育率產生滯後 1~2 年負向衝擊

驗證 AI 導入對高技能工資與中低技能就業的極化效果，是否需要經過 4~8 季的婚姻與懷孕籌備期，才反應於統計出生率的顯著驟降。

研究假說 H2 名目解耦假說

總體名目榮景帶動資產價格，但實質薪資滯後對家庭生育形成財政約束

電子零組件出口與 M1B/M2 貨幣成長並未帶動實質平均薪資同步增長，房價與 CPI 住宅類累積增幅擠壓家庭可支配所得，造成人口紅利解耦。

Reproducible Python Analytics Code

AREMOS 資料清洗與 DLM 分析程式碼

import pandas as pd
import numpy as np
import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller
from statsmodels.stats.stattools import durbin_watson

# 1. 載入並處理 AREMOS 匯出 CSV 資料檔
def load_and_clean_aremos(file_path):
    try:
        df = pd.read_csv(file_path, encoding='cp950')
    except UnicodeDecodeError:
        df = pd.read_csv(file_path, encoding='utf-8-sig')
    
    # 處理 AREMOS 缺值記號
    df = df.replace(['...', '-', ' ', ''], np.nan)
    df.rename(columns={df.columns[0]: 'Date'}, inplace=True)
    
    # 時間序列轉換 (2000M01 或 2000Q1 格式)
    df['Date'] = pd.to_datetime(df['Date'].astype(str).str.replace('M', '-').str.replace('Q', '-'))
    df = df.dropna(subset=['Date']).sort_values('Date').set_index('Date')
    
    for col in df.columns:
        df[col] = pd.to_numeric(df[col], errors='coerce')
    return df.ffill().bfill()

# 2. 實質變數計算與對數滯後特徵工程
def build_features(df):
    # 計算實質薪資 (Real Wage)
    df['Real_Wage'] = (df['Nominal_Wage'] / df['CPI']) * 100
    
    # 取自然對數
    df['ln_Birth'] = np.log(df['Birth_Rate'])
    df['ln_RealWage'] = np.log(df['Real_Wage'])
    df['ln_AIShock'] = np.log(df['AI_Exports'])
    df['ln_Housing'] = np.log(df['Housing_CPI'])
    
    # 建立 1~4 季滯後變數 (Lag Features)
    for lag in range(1, 5):
        df[f'ln_RealWage_lag{lag}'] = df['ln_RealWage'].shift(lag)
        df[f'ln_AIShock_lag{lag}'] = df['ln_AIShock'].shift(lag)
        
    return df.dropna()

# 3. 執行迴歸模型與單根檢定
df_clean = build_features(df_raw)

# ADF 平穩性檢定
adf_res = adfuller(df_clean['ln_Birth'].diff().dropna())
print(f"ADF Statistic (Diff): {adf_res[0]:.4f}, p-value: {adf_res[1]:.4f}")

# OLS 分佈滯後模型 (DLM) 估計
X_vars = ['ln_RealWage_lag4', 'ln_AIShock_lag4', 'ln_Housing', 'M1B_YoY']
X = sm.add_constant(df_clean[X_vars])
y = df_clean['ln_Birth']

model = sm.OLS(y, X).fit(cov_type='HAC', cov_kwds={'maxlags': 4})
print(model.summary())
print("Durbin-Watson Stat:", durbin_watson(model.resid))

專題研究結論與政策意涵

實證結果證實，AI 自動化與產業技術升級若僅反映於名目 GDP 與出口成長，而未同步平抑青年世代之居住與托育實質開支，將透過 **1~2 年的時滯傳導** 對總生育率形成衝擊。政策層面應規劃「自動化紅利共享機制」，以高科技產業稅收專款補貼基層青年育兒津貼與社會住宅，降低科技發展對人口永續的副作用。
